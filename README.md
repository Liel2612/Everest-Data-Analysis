# Everest Expeditions Data Analysis 🏔️

## Overview
This repository contains a comprehensive three-part analytical project on Mount Everest expeditions. The analysis explores climber success rates, the critical impact of weather conditions, and the hidden dangers of traffic bottlenecks (queue times) in the "Death Zone" using advanced machine learning and unsupervised learning techniques.

* **Part 1: Exploratory Data Analysis (EDA):** Initial data exploration, structural analysis, and statistical insights uncovering the mountain's core dynamics.
* **Part 2: Predictive Modeling & Error Analysis:** Implementation of machine learning models (Linear Regression, Decision Trees, Random Forest) to predict expedition outcomes, emphasizing model failure modes and threshold sensitivity.
* **Part 3: Unsupervised Learning & Anomaly Detection:** A critical investigation into the dataset's hidden structures. This phase includes Dimensionality Reduction (PCA), Sample and Feature-Space Clustering (K-Means, DBSCAN, Hierarchical), and Multi-Dimensional Anomaly Detection (Z-Score, Isolation Forest, LOF). It addresses the operational implications of False Negatives and concludes with an interactive visual dashboard.

## Data Source
The dataset is publicly available and sourced from Kaggle:
[Everest and the Death Zone: Will They Summit?](https://www.kaggle.com/datasets/sergionefedov/everest-and-the-death-zone-will-they-summit/data) by Sergio Nefedov.

## Repository Contents
* `Everest_Data_Analysis.ipynb`: The Jupyter Notebook containing the EDA and initial insights.
* `HW2_Error_Analysis.ipynb`: The Jupyter Notebook focusing on regression and classification models.
* `Final_Project_Unsupervised.ipynb`: The culminating Jupyter Notebook featuring PCA, Clustering, Anomaly Detection, theoretical reflection, and an interactive Plotly dashboard.
* `everest_summit_master.csv`: The dataset used for the analysis.
* `data_dictionary.csv`: A dictionary describing the dataset's columns and values.
