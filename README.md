# Everest Expeditions Data Analysis 🏔️
## Overview
This repository contains an Exploratory Data Analysis (EDA) on Mount Everest expeditions. The project aims to uncover patterns regarding climber success rates, the critical impact of weather conditions and the hidden dangers of traffic bottlenecks (queue times) in the "Death Zone".

## Data Source
The dataset used for this analysis is publicly available and sourced from Kaggle:
[Everest and the Death Zone: Will They Summit?](https://www.kaggle.com/datasets/sergionefedov/everest-and-the-death-zone-will-they-summit/data) by Sergio Nefedov.

## Repository Contents
* `Everest_Data_Analysis.ipynb`: The main Jupyter Notebook containing the Python code, visualizations, and analytical insights.
* `everest_summit_master.csv`: The dataset used for the analysis.
* `data_dictionary.csv`: A dictionary describing the dataset's columns and values.
