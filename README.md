# Everest Expeditions Data Analysis 🏔️

## Overview
This repository contains a comprehensive two-part analytical project on Mount Everest expeditions, exploring climber success rates, weather impacts, and queue times in the "Death Zone".

* **Part 1: Exploratory Data Analysis (EDA):** Initial data exploration, visualizations, and statistical insights uncovering the mountain's core dynamics.
* **Part 2: Predictive Modeling & Error Analysis:** Implementation of machine learning models (Linear Regression, Decision Trees, Random Forest) to predict expedition outcomes. This section features a deep dive into model failure modes, threshold sensitivity, and the critical operational impact of False Positives.

## Data Source
The dataset used for this analysis is publicly available and sourced from Kaggle:
[Everest and the Death Zone: Will They Summit?](https://www.kaggle.com/datasets/sergionefedov/everest-and-the-death-zone-will-they-summit/data) by Sergio Nefedov.

## Repository Contents
* `Everest_Data_Analysis.ipynb`: The Jupyter Notebook containing the EDA, visualizations, and initial insights(Homework Assignment 1).
* `Error_Analysis.ipynb`: The Jupyter Notebook focusing on regression and classification models alongside systematic error analysis (Homework Assignment 2).
* `everest_summit_master.csv`: The dataset used for the analysis.
* `data_dictionary.csv`: A dictionary describing the dataset's columns and values.
